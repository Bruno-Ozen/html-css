# Estudos de HTML e CSS

Este repositório reúne anotações, exercícios e experimentos realizados durante uma tentativa de estudar **HTML5 e CSS3** a partir do curso do professor Gustavo Guanabara, do Curso em Vídeo.

> **Importante:** este repositório **não representa a conclusão do curso inteiro**. Ele registra apenas parte do meu contato inicial com desenvolvimento web. Embora eu tenha tentado acompanhar os conteúdos e praticar alguns exercícios, ainda não considero que tenha adquirido domínio de HTML ou CSS.

A finalidade deste projeto é documentar honestamente uma etapa de aprendizado: os primeiros contatos com a estrutura de páginas web, estilização, organização visual e alguns recursos de layout.

## Curso de referência

[**Curso de HTML5 e CSS3 — Gustavo Guanabara / Curso em Vídeo**](https://www.youtube.com/watch?v=Ejkb_YpuHWs&list=PLHz_AreHm4dkZ9-atkcmcBaMZdmLHft8n)

O curso apresenta os fundamentos necessários para começar a criar páginas web com HTML5 e CSS3. Entre os temas abordados estão a estrutura de documentos HTML, tags, textos, links, imagens, listas, cores, fontes, estilos, semântica, tabelas, formulários, interfaces, posicionamento, Flexbox, Grid e responsividade.

O material oficial do curso também é composto por aulas, exercícios, desafios e materiais de apoio. O repositório atual não contém todo esse percurso: ele contém somente os exercícios e experimentos que consegui acompanhar ou reproduzir durante o período de estudo.

## Objetivos do repositório

- Ter um primeiro contato prático com HTML5;
- Entender a estrutura básica de uma página web;
- Praticar a criação de documentos HTML;
- Conhecer a função do CSS na estilização de páginas;
- Experimentar cores, fontes, espaçamentos e posicionamento;
- Observar como diferentes elementos se organizam na tela;
- Registrar tentativas, exercícios e experimentos de aprendizagem;
- Identificar os pontos que ainda precisam ser estudados com mais profundidade.

## Conteúdos praticados

### Estrutura HTML

Os primeiros exercícios servem como experimentos para compreender a estrutura básica de uma página, incluindo elementos como:

- `html`;
- `head`;
- `body`;
- Títulos e subtítulos;
- Parágrafos;
- Quebras de linha;
- Links;
- Imagens;
- Listas;
- Elementos semânticos e de conteúdo.

### Estilização com CSS

Os exercícios também registram tentativas de aplicar estilos às páginas, trabalhando com recursos como:

- Cores de fundo e de texto;
- Tipografia;
- Tamanhos;
- Espaçamentos;
- Bordas;
- Alinhamento;
- Seletores;
- Classes e identificadores;
- Organização visual dos elementos.

### Flexbox

A pasta `estudos-flexbox` reúne experimentos relacionados ao modelo de layout Flexbox, utilizado para organizar elementos em linhas ou colunas e facilitar o alinhamento de componentes.

O estudo desse recurso envolve conceitos como:

- `display: flex`;
- Direção dos elementos;
- Alinhamento horizontal e vertical;
- Distribuição de espaço;
- Quebra de linhas;
- Relação entre contêiner e itens.

### CSS Grid

As pastas `estudos-grid` e `desafio005grid` registram exercícios relacionados ao CSS Grid, um modelo de layout baseado em linhas e colunas.

Os experimentos servem como introdução a:

- `display: grid`;
- Colunas e linhas;
- Espaçamento entre elementos;
- Posicionamento em uma grade;
- Criação de layouts mais estruturados.

### Desafios

As pastas `desafio005` e `desafio005grid` reúnem tentativas de resolver desafios propostos durante os estudos. Elas representam a passagem da simples reprodução de exemplos para a tentativa de construir uma solução visual própria.

### Experimentos com IA

As pastas `testecopilot` e `testecopilot2` representam experimentos separados relacionados ao uso de ferramentas de assistência por inteligência artificial durante o aprendizado.

A IA foi utilizada como apoio para testar ideias, entender possibilidades de código e acelerar a investigação de dúvidas. Entretanto, o uso de uma sugestão automática não significa domínio do conteúdo: cada solução ainda precisa ser lida, testada e compreendida progressivamente.

## O que aprendi até aqui

Mesmo sem ter concluído o curso ou alcançado domínio da tecnologia, este repositório contribuiu para que eu tivesse contato com:

- A diferença entre estrutura e apresentação em uma página web;
- A função do HTML como linguagem de marcação;
- A função do CSS como linguagem de estilização;
- A importância da organização semântica dos elementos;
- A relação entre elementos-pai e elementos-filho;
- O uso de classes e identificadores;
- A organização de layouts com Flexbox;
- A organização de layouts com Grid;
- A necessidade de testar o resultado diretamente no navegador;
- A importância de consultar a documentação e investigar erros visuais.

## Limitações atuais

Este projeto deve ser interpretado como um registro de estudo inicial, e não como uma demonstração de domínio de desenvolvimento frontend.

Ainda preciso evoluir em pontos como:

- Semântica e acessibilidade;
- Organização de CSS em projetos maiores;
- Responsividade;
- Design visual consistente;
- Arquitetura de páginas web;
- Reutilização de estilos;
- JavaScript e interatividade;
- Boas práticas de frontend;
- Testes em diferentes navegadores e tamanhos de tela;
- Criação de projetos completos e publicados.

Reconhecer essas limitações faz parte do próprio processo de aprendizagem. O objetivo deste repositório é mostrar o ponto de partida e os experimentos realizados, sem apresentar os estudos como uma formação concluída.

## Como visualizar os exercícios

A maioria dos exercícios pode ser aberta diretamente no navegador:

1. Clone o repositório:

```bash
git clone https://github.com/Bruno-Ozen/html-css.git
```

2. Entre na pasta do projeto:

```bash
cd html-css
```

3. Abra um dos arquivos `.html` dentro de `exercicios` usando um navegador.

Também é possível abrir o projeto no Visual Studio Code e utilizar uma extensão como Live Server para atualizar a página automaticamente durante os estudos.
